# Accessible Radio Player

A fully accessible Flutter radio player app designed for blind users, featuring online radio streaming, station management, recording capabilities, and comprehensive text-to-speech support.

## Features

### Core Functionality
- **Online Radio Streaming**: Stream radio stations from any URL
- **Station Management**: Add, edit, view, and delete radio stations
- **Favorites**: Mark stations as favorites for quick access
- **Radio Recording**: Record live radio streams to local storage
- **Recordings Library**: View, play, and manage recorded content

### Accessibility Features
- **Text-to-Speech (TTS)**: Full voice feedback for all actions
- **Screen Reader Support**: Compatible with Android TalkBack
- **Large Touch Targets**: All interactive elements are easily tappable
- **High Contrast UI**: Clear visual design with good color contrast
- **Semantic Labels**: All UI elements have descriptive labels
- **Voice Announcements**: Status updates and navigation announcements
